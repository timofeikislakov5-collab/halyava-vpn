# 🆓 Халява VPN — бесплатные серверы одной ссылкой

Каждые 3 часа робот собирает бесплатные VPN-серверы, которые их владельцы
сами выкладывают в открытый доступ, **проверяет, что они отвечают**,
и складывает самые быстрые в «подписки». Пользователю нужно один раз вставить
ссылку в приложение — дальше список обновляется сам.

## Как подключиться (1 минута)

1. Установите приложение:
   - Android — **v2rayNG** или **Hiddify** (Google Play / GitHub)
   - iPhone/iPad — **Streisand**, **v2RayTun** или **Happ** (App Store)
   - Windows / macOS / Linux — **Hiddify** или **Nekoray/Throne**
2. Скопируйте одну из ссылок ниже.
3. В приложении: **+** → «Импорт из буфера» / «Добавить подписку» → вставьте ссылку.
4. Обновите подписку, нажмите «Проверить задержку» и подключитесь к серверу с меньшим пингом.

| Подписка | Что внутри | Ссылка |
|---|---|---|
| 🇷🇺 Для России — всё в одной | Wi-Fi + мобильный интернет + белые списки + запасные | `https://raw.githubusercontent.com/timofeikislakov5-collab/halyava-vpn/main/vpn/sub/russia.txt` |
| 🆓 Все | лучшие ~500 проверенных серверов всех типов | `https://raw.githubusercontent.com/timofeikislakov5-collab/halyava-vpn/main/vpn/sub/all.txt` |
| VLESS | только VLESS | `.../vpn/sub/vless.txt` |
| VMess | только VMess | `.../vpn/sub/vmess.txt` |
| Trojan | только Trojan | `.../vpn/sub/trojan.txt` |
| Shadowsocks | только SS (подходит для Outline-совместимых клиентов) | `.../vpn/sub/ss.txt` |

Если приложение не понимает ссылку — возьмите вариант с `_base64` в конце
(например `all_base64.txt`).

**OpenVPN**: в папке `vpn/openvpn/` лежат файлы `.ovpn` от проекта VPN Gate
(добровольные серверы Университета Цукубы). Скачайте файл и откройте в приложении
OpenVPN Connect. Логин и пароль, если спросит: `vpn` / `vpn`.

## Важно знать пользователям

- Это **чужие бесплатные публичные серверы**. Они живут от часов до дней — поэтому
  список обновляется каждые 3 часа. Если сервер не работает, выберите другой.
- Владелец публичного сервера теоретически может видеть ваш трафик.
  **Не вводите через такие VPN пароли от банков и госуслуг**, используйте только https-сайты.
- Скорость и стабильность не гарантированы — это халява 🙂

## Как это устроено (для владельца)

- `vpn/collect.py` — скрипт-сборщик. Источники — списки `SOURCES` и `SOURCES_RU` в начале файла.
- `.github/workflows/vpn.yml` — запускает сборщик на GitHub каждые 3 часа и сохраняет результат
  в `vpn/sub/`. Ручной запуск: Actions → «Халява VPN — обновление серверов» → Run workflow.
- Ссылки `raw.githubusercontent.com` открываются у людей **только если репозиторий публичный**.
